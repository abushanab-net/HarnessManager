Bigger circles, less said on the selected route

Both circles were held back by the same thing: the readouts column and the attention cards sat inside the scene, so the map could only use the strip between them. In this round the finding and the readouts sit in a band above the map, the attention cards in a strip below it, and each circle has the whole scene.
