Onboarding and pairing

Six screens from install to the first notification. There is no account to create: the phone makes its own key, proves it saw the computer's code, and the computer decides what it may do. Permissions (camera, notifications) are asked when each is first needed, never at install.

S1

Welcome

One choice: where the data comes from.

  • The app icon sits in the Calibre dial, which fills once on open: the first thing the app teaches is the one shape it uses for every limit.
  • Two equal choices, both a scan: a computer nearby, or a hub invitation when away from home.
  • The version the computer needs is said up front, so an old desktop is not a surprise three screens later.
S2

Scan the code

The camera, with the way back to typing always visible.

  • The camera view is dark in both themes, like the system camera. The frame carries minute ticks along its edges: the dial language on a square.
  • Computers advertising a pairing on this network (mDNS) appear in the sheet while you scan.
  • Camera access is asked here, the first time, with the reason in one line.
  • Prototype: tap the frame to simulate a scan.
S3

Enter the code

Manual pairing when scanning isn't possible.

  • Six cells in two groups of three, as the desktop shows them (481 920).
  • The code's lifetime and tries left are the computer's own limits (two minutes, three tries), drained on a small dial.
  • The computer found nearby is preselected; a host:port field covers a computer on a VPN.
S4

Approve on your computer

The phone waits while the desktop decides.

  • Three matching words in the serif, large enough to compare across a desk.
  • The grants are shown as asked, not as switches: the computer's dialog has the final say (S24).
  • The wait is a draining countdown, not a spinner: it says how long the computer keeps the pairing open.
S5

Connected

What was granted and what arrived.

  • The lume seal is the same one that confirms an answered request, so "done" always looks the same.
  • The first-sync numbers count up once (9 accounts, 7 running sessions, 3 computers).
  • The other computers it knows are listed, each to be granted on its own; MINI is asleep, so it waits.
S6

Notification prompt

The value first, then the system prompt.

  • The illustration is the real private notification: “A session needs you”, nothing else.
  • Three reasons, each tied to one of the three jobs.
  • Not now is a real choice: Requests (S8) works without notifications.
