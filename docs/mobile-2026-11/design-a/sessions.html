Sessions and control

Find the session, read what it did, answer it in place, reply one line or stop the turn. The computer that runs the session stays in charge: every action is checked again there, and each outcome has its own words.

S11

Sessions

All computers, running first.

  • A state on every row in words and a mark: Needs you (the vermilion pulse), Working (filled), Idle (ring), Ended.
  • Rows needing you sort first inside Running; the computer and the age sit on the right.
  • Filters are chips that open sheets: project, account, computer, tool. Running is on by default.
S12

Session detail

The conversation, what changed, and the controls the computer allows.

  • Your prompts are ink bubbles; Claude's replies set in the serif, so who said what reads at a glance.
  • Changed files, tests and warnings fold into one step list with diff counts.
  • The waiting request answers in place: Face ID, then the card closes into a one-line receipt with the tick landing. Try it.
  • Follow starts a Live Activity for this session (see Widgets).
  • Stop is a ringed square, apart from Send, so it is never hit by mistake.
S12 · state

No control here

Disabled with the reason, never hidden.

  • Reply and Stop need a session started in Harness Manager's own terminal. This Codex session runs in Windows Terminal on LAPTOP, so the composer says so.
  • The running step has no spinner: it says “now”, the only honest thing to show without a loop.
S13

Stop confirmation

A deliberate step for the one control that can't be undone.

  • Says exactly what is sent (Ctrl+C, once), to which session and computer, and that the session stays open.
  • Ink, not red: red is never used, and vermilion is kept for what needs you. The stop glyph and the words carry the weight.
S13 · outcome

Interrupt delivered

The computer's receipt, with the route and the time.

  • The tick lands in the toast; the transcript records the stop as a line of its own.
  • Following stays on, so the Live Activity shows the session went idle.

S11 · sheet

Filter sessions

Every filter chip opens this one sheet, at the medium detent.

  • Show (Running, Today, All) as a segmented control; Project, Tool and Account as chips; Computer as a checked list, with MINI marked asleep and read-only.
  • The button says the result before you leave: “Show 2 sessions”. Reset clears everything; Cancel keeps what was there.
