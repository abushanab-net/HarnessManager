# Designer C (`c-opencode`) — Round 1 Rebuttal

Every defect raised against Design C across the six critiques (`critique-judge-craft.md`, `critique-judge-clarity.md`, `critique-lazy-user.md`, `critique-build.md`, `critique-dataviz.md`, `critique-astra.md`), answered in one line each while keeping our time-and-reset-first angle.

## 1. Reset Horizon Instrument & Data Visualization (`critique-dataviz`, `critique-judge-craft`, `critique-judge-clarity`, `critique-build`, `critique-astra`)
- **Non-linear, remapped two-zone time axis (`0–5h` and `5h–7d` with hardcoded literal ticks like `Sun (≈ codex out)` and `Tue 15:46`)**: Agree and fixed now — replaced with a separated **Capacity (`5h` & `Week` % left)** column and a **single linear 7-day (`0d → +7d`) Reset Timeline** whose ticks (`NOW`, `+1d` … `+7d`) and reset/run-out gates are 100% computed from `data.js`.
- **Bar fill multiplied capacity by time (`% left × gateX`), encoding a product of two variables**: Agree and fixed now — decoupled capacity (`% left` drawn on fixed-length zero-baseline bars) from time-to-reset (drawn on the linear `0d → 7d` timeline track).
- **Dashed "≈ pace trajectory" drawn on healthy accounts that have no run-out forecast**: Agree and fixed now — dashed trajectory and hatched starvation gap now render strictly when an account has a forecast run-out before its reset (`outMs < resetMs`).
- **Clipped run-out labels (`≈ Out Thu 03…`) overlapping reset gate text at 1280 and 1536**: Agree and fixed now — run-out starvation spans and reset gates are positioned on the linear 7-day track with non-overlapping badges.
- **Travelling flow beads inside the 5-hour bars read as a second threshold marker**: Agree and fixed now — replaced the in-bar travelling bead with a subtle live indicator dot next to the active session count (`● N open`), which freezes in Still mode.
- **Year clock drawn as soft glowing dots ("teal smudge") and accompanied by today's per-computer totals instead of 53-week totals**: Agree and fixed now — redrawn as 371 crisp radial wedge cells across a 5-step high-contrast ramp with 53-week per-computer totals beside it.
- **Latest replies `Speed (cadence)` column invented categorical labels (`Steady stream`, `Fast burst`)**: Agree and fixed now — removed the invented cadence column from the Overview table and kept numeric speed strictly inside the full Request Log modal (honoring Rule 2).
- **Tray popup truncated at 8 accounts (`slice(0, 8)`) when 12 accounts are active**: Agree and fixed now — the tray popup now renders all active accounts (`8` or `12`) in a scrollable grid.

## 2. Craft, Hierarchy, Typography & Contrast (`critique-judge-craft`, `critique-judge-clarity`)
- **Too many Start buttons on the fold (11 buttons compete with the primary hero CTA)**: Agree and fixed now — the Hero card holds the single visible primary `Start` button on the fold; lane `Start` actions appear only on row `:hover` or `:focus-within`.
- **Overuse of `JetBrains Mono` across UI badges, durations, chips, and status pills**: Agree and fixed now — switched UI chrome, pills, rings, and countdown labels to `Inter` with `font-variant-numeric: tabular-nums`, confining monospace to the Request Log, CLI commands, and folder paths.
- **Purple `PROPOSED` tag is the loudest element on the hero card and its meaning is unclear**: Agree and fixed now — restyled as a quiet, small muted-grey tag (`Proposed: prefer expiring 5h`) with self-explanatory toggle labels.
- **Light-theme contrast failures (< 4.5:1 on amber forecast text, `1 update` badge, axis ticks, and version label)**: Agree and fixed now — darkened light-theme `--amber` (`#8A4F00`), `--coral` (`#B42818`), `--teal` (`#08656C`), `--ink-muted` (`#435A64`), and `--ink-dim` (`#526A75`), and brightened dark-theme `--ink-dim` (`#829CA8`) so all text exceeds 4.5:1 WCAG AA.
- **Numbered all-caps lecture titles (`● 1 · BEST ACCOUNT TO USE NOW · RESET RUNWAY`) and explanatory subtitle under `Add account`**: Agree and fixed now — replaced with concise plain labels (`Use next · Reset runway`, `Runs out first`, `Running now`) and removed the explanatory subtitle under `Add account`.
- **Hero account name breaking mid-word (`service-account-/resal`) and ring labels truncating at 1280**: Agree and fixed now — prevented mid-word breaks with `white-space: nowrap` on account identifiers and widened the account name column.
- **Accounts page opens with the daily stacked chart unfolded at 1280, pushing account rows down**: Agree and fixed now — the daily stacked chart folds compactly so multiple account rows sit immediately above the fold at 1280.

## 3. Data Truth, Derived Summaries & Prototype Leaks (`critique-build`, `critique-astra`, `critique-judge-clarity`, `critique-lazy-user`)
- **35 hardcoded fixture strings in views/modals (`$571.37`, `12 live · 6 elsewhere`, `next reset 01:48`, `fable ≈ Tue 08:04`, etc.)**: Agree and fixed now — every headline, recommendation, nav count, group reset, model breakdown, and status chip is computed dynamically from `data.js`.
- **First-run and Empty (0) states still show `12 live · 6 elsewhere`, `$571.37`, `Sessions 18`, `Projects 23`, and `3 computers`**: Agree and fixed now — First-run and Empty states compute `0 live · 0 elsewhere`, `$0.00`, `0` sessions, `0` projects, `1 computer`, and `Limits not read`.
- **Add account capability matrix wrong for OpenCode, Antigravity, Pi, and Oh My Pi**: Agree and fixed now — updated `data.js` and the Add Account modal so `Subscription` is supported on all 6 tools, `API key` on Claude Code, Codex, and Pi only, `Routed` on Claude Code, Codex, OpenCode, Pi, and Oh My Pi, and `Antigravity` is Subscription-only.
- **Newly added account immediately shows `100%` ring and reset times before ever being read, and switches from Empty to the 8-account preset**: Agree and fixed now — newly created accounts start with `measured: false`, `windows: []`, and `—` ("Limits not read"), and stay in the user's current state preset.
- **`Running now` only shows the first 3 local (`DEV-PC`) sessions and hides remote computers behind unlabeled colored dots**: Agree and fixed now — `Running now` groups and displays live sessions across all three named computers (`DEVELOPMENTPC`, `SAMYMSI`, `Samys-MacBook-Pro`) with named filter pills.
- **Prototype leaks in product chrome (`Test "nothing"` button in Needs attention, `Load Owner's 8 Accounts Demo` in empty state, and `5 open` header with 4 items)**: Agree and fixed now — removed the in-card test/demo buttons and bound the Needs attention counter to the exact rendered array length.
- **In the 12-account fixture, `claude-audit` is described as "Exhausted" while having `1%` left**: Agree and fixed now — updated `claude-audit`'s 5-hour window to `used: 100, left: 0` so exhausted means `0% left`.
- **Provider hop (`OpenAI Direct`, `Anthropic Direct`) shown in the route bar**: Agree and fixed now — simplified the route bar to `Computer → Account → Tool (version · first reply ≈ Xs · N open)` without a separate provider node.

## 4. Interaction, Keyboard Focus, Redraw & Completeness (`critique-build`, `critique-judge-clarity`, `critique-astra`, `critique-lazy-user`)
- **Typing in Add account calls `renderApp()` on every keystroke, destroying the focused input**: Agree and fixed now — `updateField()` updates `STATE` and patches the folder/CLI preview nodes in place without rebuilding the DOM.
- **Simulated 3-second redraw drops keyboard focus, does not restore scroll position, and restarts CSS animations**: Agree and fixed now — `renderApp()` snapshots and restores the focused element, `scrollTop`, and continuous animation phase via clock-anchored negative `animation-delay`.
- **Dialogs never take focus, do not trap `Tab`, and do not restore focus to the opener on `Escape`**: Agree and fixed now — opening any dialog moves focus to its first interactive control, traps `Tab` / `Shift+Tab` inside `.modal-card`, and restores focus to the triggering element on close.
- **Account rows on the Accounts page cannot be opened with keyboard `Enter` / `Space`**: Agree and fixed now — added `tabindex="0"` and `Enter` / `Space` keydown activation on `.acct-row` and `.t-lane`.
- **`Follow` only shows a toast instead of opening a continuing session view**: Agree and fixed now — clicking `Follow` opens a **Live Session Follow Drawer** showing the session's live output tail, project/branch, computer, and account limit windows.
- **Remove account and Export CSV only show a toast**: Agree and fixed now — removing/hiding an account mutates the active account list, and `Export CSV` triggers a real CSV file download alongside the confirmation banner.
- **Email field in Add account should be optional so users are not blocked before sign-in**: Agree and fixed now — labeled `Expected Email (optional — verified after sign-in)` and allowed empty submission.
- **247 inline `style=""` attributes in JS and fixed-width `@media` query instead of `app.css` container queries (`critique-build`)**: Agree but needs a round — consolidating every layout utility into `app.css`'s existing `@container (max-width: 70rem)` rules belongs to the Round 2 integration into `app/ui/home.js`.
